# Mozart Vertical Slice

## Goal
Only build the Mozart playable slice first. Do not expand to other musicians until this flow is complete.

## Core Flow
1. Player enters the train room.
2. Player opens Time Station.
3. Player draws the Mozart fate ticket.
4. Mozart is unlocked as the first musician.
5. Player opens the typewriter.
6. Player chats with Mozart at the selected historical time.
7. After the dialogue, player receives one collection object.
8. The collection object activates one memory fragment.
9. The memory fragment updates Mozart archive progress.
10. Player eventually receives one travel letter from Mozart.

## Allowed Scope
- Mozart only
- One ticket
- One chat flow
- One collection object
- One memory fragment
- One travel letter

## Not Allowed Yet
- Beethoven expansion
- Multiple musicians
- Complex branching
- New UI redesign
- New main interface
- New backend CMS
- Large refactor

## Development Rule
Every task must serve this slice. If a change does not help the Mozart slice run from start to finish, postpone it.
